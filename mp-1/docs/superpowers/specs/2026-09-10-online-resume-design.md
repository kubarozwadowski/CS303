# Online Resume Design

## Scope

Create a plain HTML online resume consisting of exactly six internal webpages. The pages will contain generic placeholder copy rather than personal details. No CSS or JavaScript will be added.

## Pages

- `index.html`: Resume/Home
- `linkedin.html`: LinkedIn
- `portfolio.html`: Portfolio
- `education.html`: Education
- `projects.html`: Projects
- `experience.html`: Experience

## Shared Structure

Every page will contain the required semantic elements: `header`, `nav`, `main`, and `footer`.

- The header will contain a unique `h1` page title and a generic descriptive paragraph.
- The navigation will use a `ul`, with every link nested inside an `li`, and will link to all six internal pages.
- The main element will contain generic page-appropriate headings and placeholder paragraphs. Each page's main content will differ according to its topic and include enough placeholders for later expansion.
- The footer will contain a paragraph with the copyright symbol and a link named Credits. The Credits link will point to the Resume/Home page because no separate credits page is in scope.

## Projects Page

The Projects page will include generic project placeholders followed by a clearly labeled empty section reserved for a future JavaScript calculator.

## Validation

Confirm that all six files exist, every internal link resolves to one of those files, every page contains the four required semantic elements, and `projects.html` retains the calculator placeholder at the bottom of its main content.
